三、Alpha101 公式 (前10个)

Alpha #001 — 波动率排名

rank(ts_argmax(signedpower(($returns < 0) ? stddev($returns, 20) : $close, 2), 5)) - 0.5

收益率为负时用波动率，为正时用收盘价，取平方后的5日argmax排名。

Alpha #002 — 量价相关性

-1 * correlation(rank(delta(log($volume), 2)), rank(($close - $open) / $open), 6)

成交量对数的2日变化的排名 与 日内涨跌幅的排名 的6日负相关性。

Alpha #003 — 开盘-成交量相关

-1 * correlation(rank($open), rank($volume), 10)

Alpha #004 — 最低价时序排名

-1 * ts_rank(rank($low), 9)

Alpha #005 — 开盘-VWAP偏离

rank(($open - (sum($vwap, 10) / 10))) * (-1 * abs(rank(($close - $vwap))))

Alpha #006 — 开盘-成交量裸相关

-1 * correlation($open, $volume, 10)

Alpha #007 — 放量动量

IF(mean($volume,20) < $volume, -1*ts_rank(abs(delta($close,7)),60)*sign(delta($close,7)), -1)

放量日=时序排名乘方向，缩量日=-1。

Alpha #008 — 开盘收益交叉

-1*rank((sum($open,5)*sum($returns,5))-delay(sum($open,5)*sum($returns,5),10))

Alpha #009 — 条件动量

IF(0 < ts_min(delta($close,1),5), delta($close,1), IF(ts_max(delta($close,1),5) < 0, delta($close,1), -1*delta($close,1)))

5日内全是涨或全是跌=持有动量和方向；否则反转。

Alpha #010 — 排名版条件动量(4日)

rank(同Alpha#009但窗口=4)

四、Alpha191 公式 (前10个)

Alpha #001

Alpha #003 — OBV累加

Alpha #004 — 布林带突破

IF(MA8+STD8MAvol20,1,-1)))

Alpha #005 — 量价时序排名相关

-1*tsmax(corr(tsrank($volume,5),tsrank($high,5),5),3)

Alpha #006 — 加权价格动量

Alpha #007 — VWAP偏离×量变

五、factorAnalyzer — 因子分析引擎

核心分析方法

方法功能输出
analys()全周期IC/IR/Sharpe分析多窗口(1~21天)评分 → MySQL
Sharpe(df, n=10)加权平均夏普比率10分组分层收益 → 加权夏普
ICIR(df, period=120)信息系数和比率IC = mean(corr), IR = IC/std(IC)

stock_pool(max=300)构建分析股池分层抽样: PE/PB/PS/市值各三分位
# 综合评分公式 score = |IC| × 10 + |IR| + |max_sharpe|
