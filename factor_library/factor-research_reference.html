四、Phase 4: 四阶段特征选择 ~85因子

Stage 1: IC初筛

阈值的绝对值≥0.02的因子保留。同时还要求因子的首有效索引≤90（避免数据缺失过多的因子）。输出：IC_mean, IC_IR, start_idx等统计。

Stage 2: Spearman去相关

按 quality_score = |IC| × |IC_IR| 降序排列。贪心前向选择：仅当候选因子与所有已选因子的绝对Spearman相关 < 0.7 时才收录。每对因子的相关性按日期逐日计算后取均值。

Stage 3: Lasso + Ridge

Lasso (L1): 在α∈{0.0001,0.001,0.01,0.1,1.0}中5-fold CV选最优，保留系数非零的因子。
Ridge (L2): 同样CV选α，取系数绝对值Top N（N=lasso选出数量）。

Stage 4: LightGBM

参数：num_leaves=31, lr=0.05, 1000轮+early_stopping(100)。按gain importance选Top N（N≤50）。

最终结果：Lasso ∪ LGBM → 再验证Spearman < 0.7 → ~85个因子

五、Phase 5: 6种深度学习模型

1. Linear Regression — Baseline

sklearn LinearRegression()。直接展平(样本, 因子) → 预测。IC=0.03767。

2. DNN (3层全连接)

Input(n_factors) → Linear(128)→ReLU→BN→Drop(0.2) → Linear(64)→ReLU→BN→Drop(0.2) → Linear(32)→ReLU→BN→Drop(0.2) → Linear(1)

IC=0.04234 (+12.4%)

3. DeepNet (残差网络)

Input → Linear(256)→ReLU → [ResBlock]×3 → Linear(1) ResBlock: Linear(h)→ReLU→BN→Drop(0.3) + Skip(Linear投影)

IC=0.04992 (+32.5%)

4. AlexNet (1D CNN)

Conv1d(k=3)→ReLU→MaxPool(2) ×2 → AdaptiveAvgPool(1) → 2层FC → Linear(1)

输入转置为(样本, 因子, 时间)。IC=0.03891 (+3.3%)

5. LSTM+ResNet — 🏆 最佳模型

BiLSTM(input, hidden=128) → output: (batch, seq, 256) → Transpose → Conv1d(256,64)→BN→ReLU → ResConv(64,64,64)→BN→ReLU+Skip → AdaptiveAvgPool(1) → Linear(64,1)

IC=0.06476 (+72.0%) · 双向LSTM捕捉时序依赖 + ResNet残差防止梯度消失

6. Transformer

Input Proj(d_model=128) + Learnable PE → TransformerEncoder(3层, 8头, dp=0.1) → Mean Pool → Linear(64) → Linear(1)

IC=0.05823 (+54.6%) · 注意力机制捕捉因子间交互

训练框架 (6个模型共用)

  • 数据划分：滚动时间序列CV (120天train/30天val/30天test, 步长30天) — 严格防止前视偏差
  • 预处理：每日横截面Z-Score标准化，NaN填0
  • 优化器：Adam (weight_decay=1e-4, gradient_clip=1.0)
  • 调度器：ReduceLROnPlateau (factor=0.5, patience=5)
  • 早停：validation loss patience=10, restore best weights
  • 超参优化：Optuna TPE采样器 + Median Pruner

关键结论

  • 时序结构至关重要：LSTM+ResNet 和 Transformer > 纯前馈网络
  • 残差连接显著：DeepNet (+32.5%) > DNN (+12.4%)

  • 深度 > 宽度：简单的Linear Regression效果最差

高频因子 → 聚宽（需要分钟数据）

聚宽研究环境支持分钟数据（get_price(..., frequency='1m')），但回测策略只能用日频数据。高频因子需要先在研究环境验证，再考虑是否引入策略。

ML模型 → 聚宽

聚宽策略不支持PyTorch/TensorFlow。但可以：
1. 本地训练模型，导出预测信号
2. 在聚宽策略中读取预计算的信号
3. 或用sklearn的轻量模型（聚宽支持scikit-learn）
