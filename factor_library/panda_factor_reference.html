一、PandaFactor 是什么

PandaFactor 是一个因子创建与管理平台，不是预设因子的仓库。它提供了一套完整的因子引擎：

  • 🧱 50+ 运算符函数（RANK/TS_RANK/DECAY_LINEAR/STDDEV/CORRELATION...）
  • 📊 23 个内置技术指标（MACD/KDJ/RSI/BOLL/ATR/CCI/OBV/MFI...）
  • 🔧 两种因子创建方式：公式表达式（类似 Excel 公式）+ Python 类（灵活自定义）
  • 📈 内置因子分析引擎：IC分析 / 分组收益 / 换手率 / 夏普比率
  • 🤖 LLM 集成：支持 DeepSeek 自动生成因子代码
  • 🛡️ 安全沙箱：公式模式有严格的代码安全审查（AST 静态分析）

三、运算符 Level 0 — 核心工具函数 17个

最基础的因子构造算子。

RANK(series) → Series

截⾯排名，归⼀化到 [-0.5, 0.5]

同一天横截面内对全部股票排序，最弱的=-0.5，中位=0，最强的=+0.5

RETURNS(close, period=1) → Series

计算收益率：pct_change(period)

默认1日收益率。period=5 为5日收益率

FUTURE_RETURNS(close, period=1) → Series

未来N日收益率：(shift(-N)-close)/close

用于构建因子的目标标签 (Label)

STDDEV(series, window=20) → Series

滚动标准差

每只股票独立计算，min_periods = max(2, window//4)

CORRELATION(s1, s2, window=20) → Series

两序列的滚动皮尔逊相关系数

范围 [-1, +1]。min_periods = window//2

IF(cond, true_val, false_val) → Series

条件选择：np.where(cond, A, B)

三元运算符的向量化版本。常用于构建条件因子

DELAY(series, period=1) → Series

滞后值：groupby(symbol).shift(N)

取N天前的值。DELAY(close,5) = 5天前收盘价

SUM(series, window=20) → Series

滚动求和：rolling(window).sum()

过去N天累计和。常用于做条件计数(配合布尔值)

TS_ARGMIN(series, window) → Series

窗口内最小值的位置索引

返回一个整数，0=今天，N-1=最早

TS_ARGMAX(series, window) → Series

窗口内最大值的位置（加权平均）

归⼀化到 [0,1]：0=最早发⽣，1=最新发⽣

TS_RANK(series, window=20) → Series

时间序列百分位排名

当前值在过去N天中的百分位，范围[0,1]

DELTA(series, period=1) → Series

N期差分：groupby(symbol).diff(N)

当前值 − N天前的值

ADV(volume, window=20) → Series

平均日成交量：rolling.mean()

常用于衡量流动性水平

TS_MIN(series, window=20) → Series

滚动最小值：rolling(window).min()

过去N天的最低价（或任何序列的最小值）

TS_MAX(series, window=20) → Series

滚动最大值：rolling(window).max()

过去N天的最高价

DECAY_LINEAR(series, window=20) → Series

线性衰减加权平均

权重：window, window-1, ..., 2, 1（最新日期权最大）

SCALE(series) → Series

横截⾯归⼀化到 [-1, 1]

2*(x-min)/(max-min) - 1，每组日期独立计算

四、运算符 Level 0 — 数学/统计函数 10个

LOG(series) → Series

np.log(x) — 自然对数

POWER(series, power) → Series

np.power(x, n) — N次幂

SIGN(series) → Series

np.sign(x) — 符号函数(+1/0/-1)

SIGNEDPOWER(series, n) → Series

sign(x) * |x|^n — 带符号幂

ABS(series) → Series

np.abs(x) — 绝对值

MIN(s1, s2|scalar) → Series

逐元素取最小值

可用于两序列或序列+标量

MAX(s1, s2|scalar) → Series

逐元素取最大值

常用于截断（如 MAX(ret, 0) = 只取正收益）

AS_FLOAT(condition) → Series

布尔 → 浮点：True→1.0, False→0.0

用于将条件转换为可运算的数值

COVARIANCE(s1, s2, window=20) → Series

两序列的滚动协方差

逐symbol计算，min_periods=window//4

VWAP(close, volume) → Series

成交量加权均价

Σ(price×volume)/Σ(volume)，20日滚动窗口

五、运算符 Level 0 — 移动平均函数 7个

MA(series, N) → Series

简单移动平均：rolling(N).mean()

最常用的均线函数。N=20=月线，N=60=季线

EMA(series, N) → Series

指数移动平均：ewm(span=N).mean()

α=2/(N+1)，对近期数据更敏感

SMA(series, N, M=1) → Series

中式SMA：ewm(α=M/N).mean()

alpha可自定义。中国软件常用SMA实现

DMA(series, A) → Series

动态移动平均：ewm(α=A).mean()

固定平滑因子A，需 0<A<1

WMA(series, N) → Series

加权移动平均

权重：1,2,3,...,N（最新权重最大）
Yn=Σ(i·Xi)/Σi

AVEDEV(series, N) → Series

平均绝对偏差：mean(|x-mean(x)|)

衡量序列相对均值的偏离程度

DECAYLINEAR(series, d) → Series

线性衰减加权平均（别名）

与DECAY_LINEAR等价。权重：d,d-1,...,1

六、运算符 Level 0 — 时间序列函数 10个

RD(S, D=3) → Series

四舍五入到D位小数

RET(S, N=1) → Series

取序列倒数第N个值广播到全序列

用于取最新一期数据作为常量

REF(S, N=1) → Series

向前引用：shift(N)

REF(close, 1) = 昨天收盘价

DIFF(S, N=1) → Series

N期差分：diff(N)

DIFF(close) = close[t] - close[t-1]

STD(S, N) → Series

N日滚动标准差（ddof=0）

与STDDEV的区别：ddof不同，无min_periods限制

CONST(S) → Series

用最后一个值填充全序列

将动态值转为静态常量

HHV(S, N) → Series

N日最高值：rolling(N).max()

LLV(S, N) → Series

N日最低值：rolling(N).min()

HHVBARS(S, N) → Series

距N日内最高值的天数

LLVBARS(S, N) → Series

距N日内最低值的天数

SLOPE(S, N) → Series

线性回归斜率：np.polyfit(range(N), x, 1)[0]

衡量趋势的坡度

FORCAST(S, N) → Series

线性回归预测值：np.polyval()

用过去N天回归线预测今天应有的值

TS_MEAN(series, window=20) → Series

时间序列移动平均（逐symbol）

与MA的区别：明确的多索引处理

CAP(close, shares) → Series

市值 = close × shares

七、运算符 Level 1 — 应用函数 8个

基于 Level 0 函数构建的高级逻辑函数。主要用于条件判断、计数和交叉检测。

COUNT(S, N) → Series

过去N天条件S为True的天数

COUNT(CLOSE>OPEN, 20) = 近20天收阳天数

EVERY(S, N) → Series

过去N天是否每天S都为True

EVERY(CLOSE>MA(CLOSE,20), 5) = 连续5天站上20日线

EXIST(S, N) → Series

过去N天是否存在S为True

EXIST(VOLUME>ADV(VOLUME,20)*2, 10) = 近10天有无异常放量

FILTER(S, N) → Series

S为True后，接下来N天强制为False

用于去重：信号触发后N天内不再出信号

SUMIF(S1, S2, N) → Series

条件求和

S2为True时才累加S1。常用于选择性累计

BARSLAST(S) → Series

距上一次S为True过去多少天

BARSLAST(CROSS(MA5, MA20)) = 距上次金叉天数

BARSLASTCOUNT(S) → Series

S连续为True的天数

BARSLASTCOUNT(CLOSE>OPEN) = 连阳天数

BARSSINCEN(S, N) → Series

距N天内首次S为True的天数

CROSS(S1, S2) → Series

金叉/死叉检测

S1上穿S2：(S1>S2)&(S1.shift(1)≤S2.shift(1))

LONGCROSS(S1, S2, N) → Series

维持N天后上穿

S1在连续N天<S2后，今天首次>S2

VALUEWHEN(S, X) → Series

条件回溯取值

S为True时取X的当前值，其余为NaN

八、内置技术指标 — 趋势类 8个

所有技术指标均基于 Level 0 和 Level 1 运算符构建，可直接调用。

MACD — 指数平滑异同移动平均线

📞 MACD(CLOSE, SHORT=12, LONG=26, M=9)→ (DIF, DEA, MACD_hist)
DIF = EMA(CLOSE, 12) − EMA(CLOSE, 26) DEA = EMA(DIF, 9) MACD = (DIF − DEA) × 2

DIF上穿DEA=金叉（买入），下穿=死叉（卖出）。MACD柱翻红=动能转多。

TRIX — 三重指数平滑平均线

📞 TRIX(CLOSE, M1=12, M2=20) → Series
TR = EMA(EMA(EMA(CLOSE, 12), 12), 12) TRIX = (TR − REF(TR,1)) / REF(TR,1) × 100

三重平滑去除短期噪音。TRIX上穿TRMA(20日EMA)=买点。

DMI — 趋向指标

📞 DMI(CLOSE, HIGH, LOW, M1=14, M2=6) → ADX
TR = SUM(MAX(MAX(H−L,|H−REF(C,1)|),|L−REF(C,1)|), 14) PDI = DMP×100/TR, MDI = DMM×100/TR ADX = MA(|MDI−PDI|/(PDI+MDI)×100, 6)

ADX>25=趋势明确，PDI>MDI=多头占优。ADX走高=趋势加强。

DPO — 区间震荡线

📞 DPO(CLOSE, M1=20, M2=10, M3=6) → Series
DPO = CLOSE − REF(MA(CLOSE, 20), 10)

去除长期趋势，只保留短期周期波动。正值=短期超买，负值=短期超卖。

EXPMA — 指数平均线

📞 EXPMA(CLOSE, N1=12, N2=50) → Series (短)
EXPMA_short = EMA(CLOSE, 12)

短均线上穿长均线=多头；下穿=空头。

DFMA — 双均线差值

📞 DFMA(CLOSE, N1=10, N2=50, M=10) → Series
DIF = MA(CLOSE, 10) − MA(CLOSE, 50)

正值=短期均线在上(多头)，负值=空头。值的大小代表趋势强度。

MTM — 动量线

📞 MTM(CLOSE, N=12, M=6) → Series
MTM = CLOSE − REF(CLOSE, 12)

正值=上涨动量，负值=下跌动量。MTM上穿MTMMA(6日均值)=转强。

BBI — 多空指数

📞 BBI(CLOSE, M1=3, M2=6, M3=12, M4=20) → Series
BBI = (MA(CLOSE,3) + MA(CLOSE,6) + MA(CLOSE,12) + MA(CLOSE,20)) / 4

四条均线的均值。价格站上BBI=多头市场；跌破BBI=空头市场。

九、内置技术指标 — 摆动类 7个

KDJ — 随机指标

📞 KDJ(CLOSE, HIGH, LOW, N=9, M1=3, M2=3) → K线
RSV = (CLOSE − LLV(LOW, 9)) / (HHV(HIGH, 9) − LLV(LOW, 9)) × 100 K = EMA(RSV, 3)

K>80=超买区，K<20=超卖区。K上穿D=金叉。

RSI — 相对强弱指标

📞 RSI(CLOSE, N=24) → Series [0~100]
DIF = CLOSE − REF(CLOSE, 1) RSI = SMA(MAX(DIF,0), 24) / SMA(ABS(DIF), 24) × 100

>70=超买，<30=超卖。注意：PandaFactor 的RSI默认周期24（通达信风格），不同于常见的14。

WR — 威廉指标

📞 WR(CLOSE, HIGH, LOW, N=10, N1=6) → Series [0~100]
WR = (HHV(HIGH,10) − CLOSE) / (HHV(HIGH,10) − LLV(LOW,10)) × 100

WR>80=超卖（接近N日低点），WR<20=超买（接近N日高点）。与RSI方向相反。

BIAS — 乖离率

📞 BIAS(CLOSE, L1=6, L2=12, L3=24) → Series (L1)
BIAS = (CLOSE − MA(CLOSE, 6)) / MA(CLOSE, 6) × 100

正乖离(>5%)=股价远高于均线可能回调；负乖离(<−5%)=可能反弹。

PSY — 心理线

📞 PSY(CLOSE, N=12, M=6) → Series [0~100]
PSY = COUNT(CLOSE>REF(CLOSE,1), 12) / 12 × 100

>75=市场过度乐观（可能回调）；<25=过度悲观（可能反弹）。

CCI — 商品通道指数

📞 CCI(CLOSE, HIGH, LOW, N=14) → Series
TP = (HIGH + LOW + CLOSE) / 3 CCI = (TP − MA(TP, 14)) / (0.015 × AVEDEV(TP, 14))

CCI>+100=超买异常；CCI<−100=超卖异常。突破±200为极端信号。

ROC — 变动率

📞 ROC(CLOSE, N=12) → Series
ROC = (CLOSE − REF(CLOSE, 12)) / REF(CLOSE, 12) × 100

正值=N日上涨，负值=下跌。注意：PandaFactor的实现使用百分比，Qlib的ROC是比值。

十、内置技术指标 — 通道/量价/能量类 10个

BOLL — 布林带

📞 BOLL(CLOSE, N=20, P=2) → MID
MID = MA(CLOSE, 20) UPPER = MID + 2×STD(CLOSE, 20) LOWER = MID − 2×STD(CLOSE, 20)

价格触及上轨=超买，触及下轨=超卖。带宽收窄=即将变盘。

TAQ — 唐奇安通道

📞 TAQ(HIGH, LOW, N) → UP
UP = HHV(HIGH, N)

返回N日最高价。完整通道：上轨=HHV(HIGH,N)，下轨=LLV(LOW,N)，中轨=(上+下)/2。

KTN — 肯特纳通道

📞 KTN(CLOSE, HIGH, LOW, N=20, M=10) → MID
MID = EMA((HIGH+LOW+CLOSE)/3, 20)

典型价格的三重EMA。完整：MID±M×ATR。

ATR — 平均真实波幅

📞 ATR(CLOSE, HIGH, LOW, N=20) → Series
TR = MAX(MAX(H−L, |REF(C,1)−H|), |REF(C,1)−L|) ATR = MA(TR, 20)

衡量波动性，不含方向信息。ATR增大=波动加剧。常用于止损：止损价=入场价−2×ATR。

OBV — 能量潮

📞 OBV(CLOSE, VOL) → Series
signed_vol = +VOL (if CLOSE>REF(CLOSE,1)) = −VOL (if CLOSE = 0 (if CLOSE=REF(CLOSE,1)) OBV = cumsum(signed_vol) / 10000

量在价先。OBV创新高→价格有望跟随新高；OBV与价格背离→趋势反转信号。

MFI — 资金流量指标

📞 MFI(CLOSE, HIGH, LOW, VOL, N=14) → Series [0~100]
TYP = (HIGH + LOW + CLOSE) / 3 MF = TYP × VOL MR = SUM(MF_pos, 14) / SUM(MF_neg, 14) MFI = 100 − 100/(1+MR)

成交量加权的RSI。>80=超买放量（警惕），<20=超卖缩量（机会）。与价格背离→重要反转信号。

EMV — 简易波动指标

📞 EMV(HIGH, LOW, VOL, N=14, M=9) → Series
MID = 100 × (H+L−REF(H+L,1)) / (H+L) EMV = MA(MID × (MA(VOL,N)/VOL) × (H−L) / MA(H−L,N), N)

衡量上涨/下跌所需的成交量。正值且上升=少量成交推动上涨(好)；负值=放量下跌。

MASS — 梅斯线

📞 MASS(HIGH, LOW, N1=9, N2=25, M=6) → Series
MASS = SUM(MA(H−L,9) / MA(MA(H−L,9), 9), 25)

衡量高低价差的变化趋势。MASS>27后回落=趋势可能反转。用于捕捉转折点。

ASI — 振动升降指标

📞 ASI(OPEN, CLOSE, HIGH, LOW, M1=26, M2=10) → Series
复杂的价格位移综合指标，包含对开盘/收盘/最高/最低的多层比较和加权。

ASI突破前高/前低=趋势确认信号。与价格背离=反转信号。

BRAR — 情绪指标

📞 BRAR(OPEN, CLOSE, HIGH, LOW, M1=26) → AR
AR = SUM(HIGH−OPEN, 26) / SUM(OPEN−LOW, 26) × 100

AR>120=多头强势（行情向好），AR<60=空头强势（行情低迷）。

十一、公式模式创建因子

公式语法

通过在字符串中使用 $字段名 引用数据，用内置运算符函数组合计算。

# 基础动量因子 ts_rank(returns($close), 20) # 波动率因子 stddev(returns($close), 20) # 量价相关性因子 correlation($close, log($volume+1), 20) # RSI类因子（用条件+滚动求和） sum(if($close>delay($close,1), $close-delay($close,1), 0), 14) / sum(abs($close-delay($close,1)), 14) # 复合因子：动量 + 低波动 rank(returns($close, 20)) + rank(-stddev(returns($close), 20)) # 复杂Alpha因子 correlation(rank(delta(log($volume), 1)), rank((($close-$open)/$open)), 6)
公式中的 $ 前缀表示按日期对齐的数据字段。运算符无 $ 前缀。
公式会先经过 AST 安全审查，确保不包含恶意代码。

完整表达式示例：实现一个Alpha因子

# Alpha 001: 量价偏离因子 -1 * correlation( rank(delta(log($volume), 1)), rank((($close - $open) / $open)), 6 )

逻辑：成交量变化的排名 与 日内涨跌幅的排名 之间的负相关性。更强的负相关=量价配合不佳。

十二、类模式创建因子

Factor 基类

类模式使用 Python 代码，继承 Factor 基类并实现 calculate(factors) 方法。

# 方式1：继承 Factor 基类 (PandaFactor 原生) from panda_factor.generate.factor_base import Factor import pandas as pd class MomentumFactor(Factor): """动量因子：20日收益率""" def calculate(self, factors): close = factors['close'] # 可用 self.XXX 调用所有 FactorUtils 方法 returns = self.RETURNS(close) momentum = self.SUM(returns, 20) return self.RANK(momentum)
# 方式2：转换到聚宽平台使用 from jqfactor import Factor class MOMENTUM_20(Factor): name = 'momentum_20' max_window = 20 dependencies = ['close'] def calc(self, data): close = data['close'] return close.iloc[-1] / close.iloc[0] - 1
PandaFactor 的 Factor 类与聚宽的 Factor 类名称相同但接口不同：
• PandaFactor: calculate(self, factors: dict)，factors是MultiIndex DataFrame
• 聚宽: calc(self, data: dict)，data是日期索引的DataFrame dict
虽然接口不同，但因子逻辑可以直接移植。
