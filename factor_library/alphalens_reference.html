二、数据准备函数 最重要

get_clean_factor_and_forward_returns()

整个Alphalens的入口，所有后续分析都依赖它。

参数类型/默认值说明
factorpd.Series (MultiIndex)必须。索引 (date, asset)，值=因子值
pricespd.DataFrame必须。index=日期, columns=股票代码
groupbySeries/dict, None行业分组。dict={asset: group_name}
binning_by_groupbool, False是否在组内分别计算分位数
quantilesint/seq, 5分组数。5=分5组（推荐）
periodstuple, (1,5,10)前向收益周期（天）
filter_zscoreint/None, 20⚠ 离群值过滤阈值。设为None避免前视偏差
max_lossfloat, 0.35最大允许数据丢弃比例（超则报错）

返回值: MultiIndex DataFrame

列名含义
1D, 5D, 10D各周期的前向收益率
factor原始因子值
factor_quantile因子分位数组号 (1=最低, 5=最高)
group行业分组（若传入groupby）
filter_zscore陷阱：默认值=20会基于全样本的均值和标准差过滤离群值，引入前视偏差。学术研究和实盘场景请设为 filter_zscore=None。

三、Returns 分析 — 5个核心函数

mean_return_by_quantile()

(factor_data, by_date=False, by_group=False, demeaned=True, group_adjust=False)
计算每个因子分位组的平均前向收益。返回(mean_ret, std_err)。
最常用指标：看分组收益是否单调递增。

compute_mean_returns_spread()

(mean_returns, upper_quant, lower_quant, std_err=None)
计算顶组与底组的收益差（多空利差）。值越大说明因子区分度越好。

factor_returns()

(factor_data, demeaned=True, group_adjust=False, equal_weight=False, by_asset=False)
因子加权组合的周期收益。demeaned=True=多空组合，equal_weight=True=等权。
分位数组间可比较：Q5-Q1利差是否显著。

factor_alpha_beta()

(factor_data, returns=None, demeaned=True, group_adjust=False, equal_weight=False)
OLS回归：因子组合收益 = α + β × 市场均收益 + ε
α=超额收益(年化)，β=市场暴露。α越大越好。

factor_cumulative_returns()

(factor_data, period, long_short=True, group_neutral=False, equal_weight=False)
模拟因子组合的累计收益曲线。指定period(如'5D')查看该周期的累计表现。

四、IC 分析 — 2个核心函数

factor_information_coefficient()

(factor_data, group_adjust=False, by_group=False)
Spearman Rank IC：每日因子值与N期前向收益的秩相关系数。
返回DataFrame，index=日期，columns=各周期IC序列。
IC均值>0.03=有效，IC_IR>0.3=优秀。

mean_information_coefficient()

(factor_data, group_adjust=False, by_group=False, by_time=None)
按时间/组聚合IC。by_time='M'=月均IC，by_time='W'=周均IC。
月均IC热力图可看出因子在哪些月份有效。
# IC关键指标计算 IC = corr(factor[t], forward_return[t+period])  # Spearman秩相关 IC_mean = mean(IC)                        # 因子预测能力 IC_IR = IC_mean / std(IC)                # 预测稳定性 (Information Ratio) t_stat = IC_mean / (std(IC)/sqrt(n))        # 统计显著性

五、换手率分析 — 2个核心函数

quantile_turnover()

(quantile_factor, quantile, period=1)
某分位组内，本期与上期成员不重合的比例。
高换手率=因子值波动大=策略交易成本高。
均值<0.2=低换手（好），>0.5=高换手（谨慎）。

factor_rank_autocorrelation()

(factor_data, period=1)
因子排名的自相关性。
接近1=因子值高度稳定（换手率低但可能已失效）
接近0=因子值随机变化
理想区间：0.85~0.95

六、事件/累计收益分析 — 5个函数

common_start_returns()

(factor, returns, before, after, cumulative=False, mean_by_date=False, demean_by=None)
对齐所有因子日期为共同起点(-before到+after)，计算窗口内收益。

average_cumulative_return_by_quantile()

(factor_data, returns, periods_before=10, periods_after=15, demeaned=True, group_adjust=False, by_group=False)
因子日期前后窗口内，各分位组的平均累计收益。看因子信号发出前后的收益行为。

factor_weights()

(factor_data, demeaned=True, group_adjust=False, equal_weight=False)
从因子值到组合权重的转换。demeaned=做多高因子值+做空低因子值。

cumulative_returns()

(returns)
将日收益序列转为累计收益（起始值=1）。

create_pyfolio_input()

(factor_data, period, capital=None, long_short=True, group_neutral=False)
生成pyfolio兼容的收益+仓位+基准数据，用于进一步策略分析。

九、完整代码示例 可直接运行

# === 完整因子分析 (本地Python, 用yfinance获取数据) === import alphalens as al import yfinance as yf import pandas as pd import numpy as np # 1. 获取数据 tickers = ['AAPL','MSFT','GOOGL','AMZN','META','NVDA','TSLA'] data = yf.download(tickers, start='2023-01-01', end='2024-12-31') prices = data['Adj Close'] # 2. 构造因子 (例: 20日动量) factor = prices.pct_change(20).stack() factor.index = factor.index.set_names(['date','asset']) # 3. 数据准备 factor_data = al.utils.get_clean_factor_and_forward_returns( factor, prices, quantiles=5, periods=(1,5,20) ) # 4. 一键分析 al.tears.create_full_tear_sheet(factor_data) # 5. 手动指标 ic = al.performance.factor_information_coefficient(factor_data) print(f"IC_1D mean: {ic['1D'].mean():.4f}, IR: {ic['1D'].mean()/ic['1D'].std():.3f}") print(f"IC_5D mean: {ic['5D'].mean():.4f}, IR: {ic['5D'].mean()/ic['5D'].std():.3f}")
