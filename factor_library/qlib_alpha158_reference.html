一、K-bar 形态因子 9个

基于当日 OHLC 四个价格计算的 K 线形态特征，衡量日内多空力量对比。无需历史回溯，max_window=1。

KMID — K线实体涨幅

🔧 依赖: open, close📐 max_window: 1
KMID = (Close − Open) / Open
正值 = 收阳（收盘高于开盘），负值 = 收阴。
值越大表示买盘越强，实体越长。正负 2% 以上为显著。

KLEN — K线振幅

🔧 依赖: open, high, low📐 max_window: 1
KLEN = (High − Low) / Open
衡量日内价格波动幅度。值越大=波动越剧烈。5% 以上为高波动日。

KMID2 — 标准化K线实体

🔧 依赖: open, high, low, close📐 max_window: 1
KMID2 = (Close − Open) / (High − Low + 1e⁻¹²)
排除了振幅影响的纯实体强度。接近 +1 = 光头光脚阳线（极端强势），接近 -1 = 光头光脚阴线（极端弱势），接近 0 = 十字星（多空平衡）。

KUP — 上影线比例

🔧 依赖: open, high, close📐 max_window: 1
KUP = (High − max(Open, Close)) / Open
上影线越长，说明高位卖压越大。> 2% 表示明显遇阻回落。

KUP2 — 标准化上影线

🔧 依赖: open, high, low, close📐 max_window: 1
KUP2 = (High − max(Open, Close)) / (High − Low + 1e⁻¹²)
标准化版本。接近 1 = 长上影十字或倒锤头（典型见顶信号）。

KLOW — 下影线比例

🔧 依赖: open, low, close📐 max_window: 1
KLOW = (min(Open, Close) − Low) / Open
下影线越长，说明低位买盘越强。> 2% 表示明显探底回升。

KLOW2 — 标准化下影线

🔧 依赖: open, high, low, close📐 max_window: 1
KLOW2 = (min(Open, Close) − Low) / (High − Low + 1e⁻¹²)
接近 1 = 长下影锤子线（典型见底信号）。

KSFT — 价格位移

🔧 依赖: open, high, low, close📐 max_window: 1
KSFT = (2×Close − High − Low) / Open
收盘价相对于日内中点的偏移。正值=收在偏上方，负值=收在偏下方。衡量收盘强势程度。

KSFT2 — 标准化价格位移

🔧 依赖: open, high, low, close📐 max_window: 1
KSFT2 = (2×Close − High − Low) / (High − Low + 1e⁻¹²)
标准化版本。+1 = 收在最高（最强），-1 = 收在最低（最弱）。

二、标准化价格因子 4个

当日各价格除以收盘价进行去量纲化，使不同价位的股票可以横向比较。

OPEN0 = Open/Close
HIGH0 = High/Close
LOW0 = Low/Close
VWAP0 = VWAP/Close

OPEN0 / HIGH0 / LOW0 / VWAP0

🔧 依赖: open/high/low, close (VWAP0 需 money+volume)📐 max_window: 1
OPEN0 = Open / Close # 开盘价相对于收盘价 HIGH0 = High / Close # 最高价相对于收盘价 LOW0 = Low / Close # 最低价相对于收盘价 VWAP0 = VWAP / Close # 均价相对于收盘价 (VWAP=成交额/成交量)
以收盘价为基准的归一化。OPEN0 < 1 表示高开，> 1 表示低开。
HIGH0 越接近 1 表示日内波动小，越远离 1 表示上影或冲高。
VWAP0 < 1 表示收盘价高于均价（尾盘强势），> 1 表示收盘低于均价（尾盘弱势）。
通常用作其他因子的控制变量，或在 ML 模型中作为输入特征。单独使用选股能力较弱。

三、成交量因子 1个

原始成交量标准化，消除不同股票之间的量级差异。

VOLUME0

🔧 依赖: volume📐 max_window: 1
VOLUME0 = Volume / (Volume + 1e⁻¹²) ≈ 1
实际值恒为 1（自除）。这个因子通常配合其他成交量因子使用。完整 Alpha158 默认配置中不包含 volume 因子。

四、动量因子 — ROC (Rate of Change) 5个

衡量价格在过去 N 天内的变化幅度，是最经典的趋势跟踪因子。

ROC5 / ROC10 / ROC20 / ROC30 / ROC60

🔧 依赖: close📐 max_window: 6~61
ROC(d) = Close[t−d] / Close[t] # 原始 Qlib 表达式: Ref($close, d) / $close # d 天前的收盘价 / 今天的收盘价
ROC > 1：过去 d 天价格上涨（值越大涨幅越大）
ROC = 1：价格不变
ROC < 1：过去 d 天价格下跌

举例：ROCE20 = 1.15 表示 20 天前价格只有现在的 87%，即涨了 15%。
ROCE20 = 0.85 表示跌了 15%。
正向因子：ROC 越大越好（动量效应）。
在 A 股中，20 日和 60 日动量效果较好；5 日可能捕捉短期反转。
因子名窗口max_window衡量
ROC55天6周度动量
ROC1010天11双周动量
ROC2020天21月度动量
ROC3030天31月半动量
ROC6060天61季度动量

五、均线因子 — MA (Moving Average) 5个

简单移动平均相对当前价格的比值，衡量当前价格在均线上方还是下方。

MA5 / MA10 / MA20 / MA30 / MA60

🔧 依赖: close📐 max_window: 5~60
MA(d) = Mean(Close[t−d+1 : t]) / Close[t] # Qlib: Mean($close, d) / $close # d 日均值 / 当日收盘价
MA < 1：收盘价在均线 上方（多头排列）
MA > 1：收盘价在均线 下方（空头排列）
MA = 1：价格正好在均线上

注意：MA 值 越小 表示价格相对均线越高，和直觉相反！
反向因子（MA 越小越好）。常配合 ROC 使用 —— ROC 看方向，MA 看位置。

六、波动率因子 — STD 5个

收盘价的标准差相对于当前价格，衡量近期价格波动的剧烈程度。

STD5 / STD10 / STD20 / STD30 / STD60

🔧 依赖: close📐 max_window: 5~60
STD(d) = Std(Close[t−d+1 : t]) / Close[t] # Qlib: Std($close, d) / $close
高 STD：近期价格波动大，不确定性高，风险溢价可能也高。
低 STD：价格平稳，横盘整理中。
极端高 STD 可能暗示恐慌或暴涨后的不稳定。
中性因子。适中的波动率配合动量效果更好（"稳中带涨"）。
也可以用来过滤高波动股票，降低组合风险。
STD20 > 5% 视为高波动，STD20 < 1% 视为低波动。

七、趋势因子 — BETA / RSQR / RESI 15个

对过去 N 天收盘价做线性回归，提取斜率和拟合度，比简单的 ROC 更能捕捉趋势的强度和稳定性。

BETA5~60 — 价格趋势斜率

🔧 依赖: close📐 max_window: 5~60
BETA(d) = β / Close[t] # β = Cov(天数序列, 收盘价序列) / Var(天数序列) # Qlib: Slope($close, d) / $close # 即：对过去 d 天收盘价做 y = α + β·x 回归，β 为斜率
BETA > 0：上升趋势（斜率越大=涨得越快）
BETA < 0：下降趋势
接近 0：横盘无趋势

与 ROC 的区别：ROC 只看首尾，BETA 考虑了整段路径，对噪音更鲁棒。

RSQR5~60 — 趋势拟合度 (R²)

🔧 依赖: close📐 max_window: 5~60
RSQR(d) = R² = 1 − SS_residual / SS_total # Qlib: Rsquare($close, d) # 线性回归的决定系数，衡量价格走势有多"直"
RSQR 接近 1：价格走势非常线性（趋势明确，无论涨跌）
RSQR 接近 0：价格走势杂乱无章（震荡、反复）

配合 BETA 使用：BETA>0 且 RSQR>0.7 = 稳健上升趋势（高确定性）。
BETA>0 但 RSQR<0.3 = 虽有涨幅但波动大，趋势不可靠。

RESI5~60 — 趋势偏离残差

🔧 依赖: close📐 max_window: 5~60
RESI(d) = (Close[t] − ŷ[t]) / Close[t] # ŷ[t] = α + β · (d−1) 即回归线对今天的预测值 # Qlib: Resi($close, d) / $close
RESI > 0：今天收盘价 高于 趋势线预测（超预期走强，可能加速）
RESI < 0：今天收盘价 低于 趋势线预测（走弱，可能反转）
接近 0：价格精准落在趋势线上

这是 短期择时信号：RESI 正值可能预示趋势加速。

八、极值与分位因子 — MAX / MIN / QTLU / QTLD 20个

衡量当前价格在过去 N 天的价格区间中所处的位置。

MAX5~60 — N日最高价

🔧 依赖: close, high📐 max_window: 5~60
MAX(d) = Max(High[t−d+1 : t]) / Close[t]
接近 1 = 价格接近 N 日新高。>1 = 正常（历史高点除以当前价格）。

MIN5~60 — N日最低价

🔧 依赖: close, low📐 max_window: 5~60
MIN(d) = Min(Low[t−d+1 : t]) / Close[t]
接近 1 = 价格接近 N 日新低。<1 = 正常（历史低点低于当前价）。MIN 越小表示当前价越高于历史低点。

QTLU5~60 — N日收盘价 80% 分位数

🔧 依赖: close📐 max_window: 5~60
QTLU(d) = Quantile₀.₈(Close[t−d+1 : t]) / Close[t]
QTLU < 1 = 当前价超过了过去 80% 的价格水平（处于高位）；QTLU > 1 = 当前价低于 80% 分位。

QTLD5~60 — N日收盘价 20% 分位数

🔧 依赖: close📐 max_window: 5~60
QTLD(d) = Quantile₀.₂(Close[t−d+1 : t]) / Close[t]
QTLD < 1 = 当前价远高于 20% 分位（不是底部）；QTLD > 1 = 当前价接近或低于 20% 分位（处于低位）。

九、价格位置因子 — RANK / RSV 10个

精确衡量当前价格在过去 N 天中的相对排名和位置。

RANK5~60 — 价格百分位排名

🔧 依赖: close📐 max_window: 5~60
RANK(d) = Rank_In_Window(Close[t], Close[t−d+1 : t]) / d # 返回 0~1，当前价在 d 天窗口中的排名百分位
RANK → 1.0：当前价是 N 天内的最高价（处于高位，可能超买）
RANK → 0.0：当前价是 N 天内的最低价（处于低位，可能超卖）
RANK ≈ 0.5：当前价在 N 天中间位置

⚠️ 注意方向：RANK 高意味着价格在高位，可能考虑反转逻辑（做空高位股）或动量逻辑（强者恒强），取决于你的策略风格。

RSV5~60 — 价格区间位置 (KDJ 同源)

🔧 依赖: close, high, low📐 max_window: 5~60
RSV(d) = (Close[t] − Min(Low, d)) / (Max(High, d) − Min(Low, d) + 1e⁻¹²) # 这是 KDJ 指标的原始 RSV 值
RSV = 1.0：当前收盘 = N 日最高价（极端高位）
RSV = 0.0：当前收盘 = N 日最低价（极端低位）
RSV = 0.5：当前价在 N 日区间正中间

与 RANK 的区别：RSV 考虑的是价格在「最高-最低」区间的位置，RANK 是收盘价之间的排名。RSV 对极端波动更敏感。
RSV > 0.8 且 RANK > 0.8 → 价在历史高位且接近区间上沿，超买信号强烈。
RSV < 0.2 且 RANK < 0.2 → 超卖信号强烈。

十、Aroon 指标因子 — IMAX / IMIN / IMXD 15个

Aroon 指标衡量距上次创新高/新低的时间长短，用于判断趋势强度和方向。

IMAX5~60 — Aroon Up（距新高时间）

🔧 依赖: high📐 max_window: 5~60
IMAX(d) = Days_Since_Max(High, d) / d # 距 N 日内最高价出现日过去了多少天 / N
IMAX = 0：今天就是 N 日高点（最强势）
IMAX = 1：N 天前是高点，之后一直在跌（最弱势）
IMAX < 0.3：近期有新高，趋势向上
IMAX > 0.7：很久没有新高，趋势偏弱

IMIN5~60 — Aroon Down（距新低时间）

🔧 依赖: low📐 max_window: 5~60
IMIN(d) = Days_Since_Min(Low, d) / d # 距 N 日内最低价出现日过去了多少天 / N
IMIN = 0：今天就是 N 日低点（最弱势）
IMIN = 1：N 天前是低点，之后一直在涨（最强势）
配合 IMAX：IMAX 小 + IMIN 大 = 强势上涨；IMAX 大 + IMIN 小 = 弱势下跌

IMXD5~60 — Aroon 差值

🔧 依赖: high, low📐 max_window: 5~60
IMXD(d) = (IdxMax(High,d) − IdxMin(Low,d)) / d
IMXD > 0：高点先于低点出现（下跌趋势中）
IMXD < 0：低点先于高点出现（上涨趋势中）
接近 0：高点和低点同时或趋势不明

IMXD 本质上 = Aroon_Up − Aroon_Down 的相反数。

十一、量价相关性因子 — CORR / CORD 10个

衡量价格与成交量、价格变化率与成交量变化率之间的联动关系。

CORR5~60 — 价量相关性

🔧 依赖: close, volume📐 max_window: 5~60
CORR(d) = Corr(Close, Ln(Volume+1), d) # 过去 d 天收盘价与对数成交量的皮尔逊相关系数
CORR → +1：价量同向（涨时放量，跌时缩量 = 健康的量价配合）
CORR → -1：价量背离（涨时缩量，跌时放量 = 不健康的信号）
CORR ≈ 0：价量无关联

正向因子：价量同向配合通常意味着趋势有成交量支撑。

CORD5~60 — 收益率-量变相关性

🔧 依赖: close, volume📐 max_window: 6~61
CORD(d) = Corr(Return, Ln(1 + ΔVolume), d) # Return = Close/Ref(Close,1) − 1 # ΔVolume = Volume/Ref(Volume,1) − 1 # 日收益率与日成交量变化率的相关性
比 CORR 更精细：用「变化率」替代「绝对水平」，剔除趋势性影响。
CORD > 0：放量日涨，缩量日跌（健康）
CORD < 0：放量日跌，缩量日涨（警惕）

十二、涨跌比例因子 — CNTP / CNTN / CNTD 15个

统计过去 N 天的涨跌天数比例，反映多空力量的持续性。

CNTP = 上涨天数/d
CNTN = 下跌天数/d
CNTD = CNTP − CNTN

CNTP(d) / CNTN(d) / CNTD(d)

🔧 依赖: close📐 max_window: 6~61
CNTP(d) = Count(Close > Ref(Close,1), d) / d # 上涨天数比例 CNTN(d) = Count(Close < Ref(Close,1), d) / d # 下跌天数比例 CNTD(d) = CNTP − CNTN # 净涨跌天数比例，范围 [−1, +1]
CNTP=0.7 且 CNTN=0.3：过去 N 天 70% 的日子在涨 → 多头主导。
CNTD → +1：连续上涨，强势多头。
CNTD → -1：连续下跌，弱势空头。
CNTD ≈ 0：涨跌参半，震荡格局。

与 ROC 的区别：ROC 看幅度，CNT 看天数频率。一只股票可能 CNTP 高但 ROC 低（小涨多天），或 CNTP 低但 ROC 高（一天暴涨）。
正向因子。CNTD 越大越好。CNTD20 > 0.3 表示过去一个月明显偏多。

十三、RSI 类强度因子 — SUMP / SUMN / SUMD 15个

类似 RSI 指标的概念：涨幅占总波动的比例，衡量上涨力量 vs 下跌力量。

SUMP = Σ涨幅/Σ总波动
SUMN = Σ跌幅/Σ总波动
SUMD = SUMP − SUMN

SUMP(d) / SUMN(d) / SUMD(d)

🔧 依赖: close📐 max_window: 6~61
SUMP(d) = Σmax(ΔClose,0) / Σ|ΔClose| # 涨幅占绝对波动的比例 → RSI 类指标 SUMN(d) = Σmax(−ΔClose,0) / Σ|ΔClose| # 跌幅占绝对波动的比例 SUMD(d) = (ΣΔClose) / Σ|ΔClose| # 净涨跌 / 总波动 → 范围 [−1, +1] # 注意：SUMP + SUMN ≡ 1，SUMD = SUMP − SUMN = 2×SUMP − 1
SUMP=0.7 且 SUMN=0.3：涨幅占 70% 的波动能量 → 多头力量远超空头。
SUMP=0.3 且 SUMN=0.7：跌幅占主导 → 空头主导。
SUMD > 0.5：显著偏多。SUMD < -0.5：显著偏空。

与 CNTD 的区别：CNTD 只计天数（涨了几天），SUMD 计幅度（涨了多少）。
一只股票可能连涨多天但都是小阳线（CNTD 高，SUMD 一般），也可能一根大阳线逆转（CNTD 低，SUMD 高）。
正向因子。SUMD 的效果通常优于 CNTD（幅度信息更丰富）。
SUMP 也可用于构建"稳定上涨"的因子：ROC>1 且 SUMP>0.6。

十四、成交量形态因子 — VMA / VSTD / WVMA / VSUMP / VSUMN / VSUMD 30个

成交量自身的趋势、波动和力量对比。量在价先，成交量形态对价格走势有预判作用。

VMA5~60 — 成交量均线

🔧 依赖: volume📐 max_window: 5~60
VMA(d) = Mean(Volume, d) / (Volume[t] + 1e⁻¹²)
VMA > 1：当日成交量低于 N 日均量（缩量）
VMA < 1：当日成交量高于 N 日均量（放量）
VMA 越小 = 放量越明显。
放量上涨 = 强势确认；放量下跌 = 恐慌出逃；缩量上涨 = 动力不足。

VSTD5~60 — 成交量波动率

🔧 依赖: volume📐 max_window: 5~60
VSTD(d) = Std(Volume, d) / (Volume[t] + 1e⁻¹²)
高 VSTD = 成交量忽大忽小（不稳定），低 VSTD = 成交量稳定。异常放量日会拉高 VSTD，值得警惕。

WVMA5~60 — 成交量加权价格波动率

🔧 依赖: close, volume📐 max_window: 6~61
WVMA(d) = Std(|Return| × Volume, d) / (Mean(|Return| × Volume, d) + 1e⁻¹²) # 放量日的价格波动幅度是否稳定
高 WVMA：大成交量日的价格波动幅度差异大（量价关系不稳定）
低 WVMA：无论放量缩量，价格波动幅度相对一致（量价关系稳定）
这是衡量量价结构质量的指标。

VSUMP(d) / VSUMN(d) / VSUMD(d) — 成交量 RSI

🔧 依赖: volume📐 max_window: 6~61
VSUMP(d) = Σmax(ΔVol,0) / Σ|ΔVol| # 放量天数占绝对量变的比例 VSUMN(d) = Σmax(−ΔVol,0) / Σ|ΔVol| # 缩量天数占绝对量变的比例 VSUMD(d) = (ΣΔVol) / Σ|ΔVol| # 净放量比例
VSUMD > 0：成交量整体在放大（= 市场关注度上升）
VSUMD < 0：成交量整体在萎缩（= 市场关注度下降）

经典组合：VSUMD>0（量升）+ ROC20>1（价涨）= 量价齐升，牛市信号。
VSUMD>0（量升）+ ROC20<1（价跌）= 放量下跌，危险信号。
